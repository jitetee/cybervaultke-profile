## What I build


JITETEE is a product studio focused on useful software for everyday work and learning, with an emphasis on reliable tools, clear interfaces, and low-resource environments.


- Learning platforms, courses, quizzes, and study tools
- Business automation and messaging workflows
- Digital products, online services, and customer operations
- Developer utilities for Android, Termux, Firebase, and Python
